📖 How to Add a New Store to HintaTutka

Step 1: Harvest the Store DOM

Open any product page in your browser. Right-click anywhere on the page and select Inspect or View Page Source. Copy the HTML and paste it into the Harvester Studio tab above, or use the CLI:

node scripts/harvest-store.mjs https://www.newstore.fi/product/12345

Step 2: Hot-Patch via selectors.json (Zero Reinstall)

Add the generated selector block to selectors.json. The userscript and Chrome extension automatically fetch this file every 12 hours, giving all users instant support without requiring a script update!

Step 3: Save Test Fixture & Verify

Save the HTML snapshot into tests/fixtures/ and run the test suite to ensure 100% zero-regression protection:

node --test
